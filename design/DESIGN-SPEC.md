# 喜帖設計規格

給 Haley（設計師）之後調整版型、配色、素材用的規格文件。對應的 Figma 檔與網站視覺都是照這份規格走。

---

## 1. 設計方向

- 主軸是**自然極簡**：留白、細線、襯線字體，不走花俏的傳統喜帖路線。
- 配色**帶聖誕感但原本不放聖誕元素**（婚期在聖誕節前後）；後來規則放寬，**聖誕紅、松果、松針枝、紅莓串都可以用**，只是仍用水彩、線稿等柔和畫法呈現，不做寫實聖誕插畫。
- 新娘是基督徒，**十字架與經文是信仰元素，不是裝飾**，設計上原則是「保留現有元素、增加資訊，不取代」——先有極簡版型，再疊信仰元素上去。

## 3. 字型

- **Noto Serif TC**：中文內文（名字、邀請文、地點、資訊小字）
- **Cormorant Garamond**：英文與數字裝飾字（Save the Date、大日期數字、英文縮寫 C & P）

中英文分開做 text node、用 auto layout 對齊，不要塞在同一個 text node 裡，避免中英文混排基線不齊。

## 4. 尺寸

- 單張喜帖：**1500 × 2100 px**（5×7 吋 @300dpi）
- 深底版文字最小 24px；霧金只用在裝飾線與縮寫，不用來寫資訊小字（對比不足）

**花簇素材規格**（給後續調整花簇位置或重畫花簇參考）：
- 圖層順序（由後到前）：松針枝 → 霧金細枝 → 尤加利葉 → 莓果串 → 小白花 → 聖誕紅（主角）→ 松果

- 已知取捨：白色小花去背後偏半透明，深底版（04、05）白花顏色會偏淡；若要更清楚的白花，需要重新出「非白底」原圖

## 6. 背面結構（v2、v3 共用一套骨架，各配自己的底色）

八層資訊，由上到下：

1. 頂部標誌：「囍」或「C & P」縮寫（見下方對照）＋上方小十字架
2. 新郎（林承宇）／新娘（陳沛瑜），左右兩欄，中間「&」
3. 男方家長／女方家長，各自兩位家長姓名
4. 分隔：細線 ＋「誠 摯 邀 請」＋ 細線
5. 日期大字：年｜月｜日，下方農曆日期與星期
6. 入席時間（例：午宴 12:00 準時入席）
7. 地點名稱、地址、電話；地點之後接「在神的愛中」句與經文
8. 結語一句話

底色與標誌對照：

## 7. 信仰元素規則

- **十字架尺寸與位置**：兩種尺寸——大 64×92px 放在 01、03；小 44×64px 放在 02、04、05。一律**霧金**色，置於文字區塊最上方（正面）／頂部標誌上方（背面）。
- **經文位置**：正面在邀請文之後加一句「在神的愛中　開啟新的旅程」，版面最底部加創世記 2:24「所以人要離開父母，與妻子連合，二人成為一體。」並附出處「創世記 2:24」。
- **地點**：因信仰元素加入，地點統一改為「青山教會 · 主堂」（原本是「青山會館」）。

## 9. 網站與紙本的關係

網站（`index.html` / `src/style.css`）以 **v3-04（node `18:20`）** 為視覺基底，色票（第 2 節 10 色）與字型（第 3 節）與 Figma 完全共用。之後在 Figma 調整配色或字型，記得同步回網站的 CSS 變數，反之亦然。
